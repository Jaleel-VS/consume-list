## Updating the list

Edit the relevant catalogue directly on GitHub or in a local checkout. Add titles with a link, status, genres, and a short premise. For a serial, include the starting episode or season when useful. New media categories can have their own Markdown files linked here.

Use `Queued`, `In progress`, `Finished`, `Paused`, `Dropped`, or `Previously listened` as the status. Keep finished and dropped titles as history. Add progress, personal ratings, and reactions only when known; keep plot spoilers out of the tables.
